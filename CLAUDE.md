# Baromètre emploi tech France

Lire METHODE.md avant toute édition. Règles :
- Réponses et livrables en français.
- Sources : uniquement des API publiques prévues pour diffuser des offres (ATS), Indeed Hiring Lab (CC BY 4.0, à citer), API France Travail. Pas de scraping de LinkedIn, ni de Welcome to the Jungle sans partenariat, ni de clés d'API embarquées.
- Ne jamais committer le texte brut des offres (`data/*/jobs_raw*.jsonl`, voir .gitignore) ; seules les métadonnées classées sont publiées.
- Une édition = un dossier `data/AAAA-MM/` + un `RESULTATS_*.md`. Toujours comparer à l'édition précédente et garder la taxonomie stable.
- Vérifier chaque chiffre marquant en relisant les offres concernées ; afficher couverture et limites.
